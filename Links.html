Seja bem-vindo ao Menu de Links!

Ir para o curso que estou estudando. # Essa tag "a" é usada para te mandar para links externos, e o atributo href é usado para definir o link que você quer ir. O texto dentro da tag "a" é o texto que vai aparecer para o usuário clicar e ir para o link. Ir para o Google em outra aba. # O atributo target é usado para definir onde o link vai abrir, e o valor "_blank" significa que o link vai abrir em uma nova aba do navegador.
Ir para meu site primário # Esse link serve para entrar em outra página do mesmo site, ao invés de utilizarmos o link, apenas pegamos o nome do arquivo. Ver site do Miguel # para selecionar algo de outra pasta, que nesse caso é equipe, utilizamos o nome da pasta e depois o nome do arquivo. Voltar para a página de Links/anterior # Para voltar para a página anterior que não esteja na mesma pasta, utilizamos o "../" para voltar uma pasta. Se precisar voltar mais de uma pasta, basta repetir o mesmo processo "../" quantas vezes forem necessárias.
